# Restaurant POS — نقطة البيع (نسخة تجريبية)

## النشر على GitHub Pages
1. أنشئ مستودعًا جديدًا وارفع كل الملفات في الجذر.
2. Settings ← Pages ← Deploy from a branch ← main ← /root.
3. افتح الرابط `https://USERNAME.github.io/REPO/` في Chrome أو Edge.

## التشغيل على الحاسوب
- من الرابط، اضغط أيقونة التثبيت في شريط العنوان (أو الإعدادات ← تثبيت كتطبيق) فيعمل كبرنامج مستقل.
- الإعدادات ← «اختيار مجلد الحفظ التلقائي»: يُحفظ بعد كل عملية `pos-backup.json` و`orders-all.csv` و`orders-التاريخ.csv` (تُفتح في Excel).
- بعد إعادة فتح المتصفح قد يطلب زر «تفعيل الحفظ التلقائي»؛ اضغطه مرة واحدة.

## تنبيهات
- البيانات في متصفح الجهاز فقط ولا تتزامن بين الأجهزة؛ استعمل المجلد أو النسخة الاحتياطية.
- الطباعة عبر نافذة المتصفح؛ الطباعة الحرارية المباشرة قد تحتاج إعدادًا إضافيًا.
- نسخة تجريبية وليست نظام إنتاج متكاملًا.
